# 🎨 Dizainer

**Dizainer** — это высокопроизводительный браузерный редактор для автоматизированной обработки и дизайна фотографий товаров под требования маркетплейсов (Ozon, Wildberries, Яндекс Маркет, Авито). 

Инструмент позволяет превратить обычное фото в профессиональную карточку товара прямо в браузере, без использования тяжелых графических пакетов и с полным контролем над приватностью данных.

## 🚀 Основные возможности
- **Умная работа с фоном**: Алгоритмическое или ручное удаление фона по цвету с настройкой допуска, с опцией сохранения естественных теней объекта.
- **Студийная замена фона**: Установка сплошного цвета, градиента, паттерна, готовой сцены или собственного фонового изображения из личной библиотеки.
- **Автокроп и обрезка**: Автоматическое определение границ объекта и удаление лишних прозрачных или однотонных полей.
- **Пресеты маркетплейсов**: Мгновенное переключение между требуемыми размерами для главных, дополнительных и миниатюрных изображений Ozon, WB, Яндекс Маркета и Авито.
- **Текстовые слои и шаблоны**: Добавление заголовков, цен, бейджей и характеристик. Готовые стилевые шаблоны (Clean, Bold, Premium, Sale, Eco, Tech, Kids, Luxury).
- **Водяные знаки**: Гибкая настройка и нанесение защитного водяного знака на все изображения.
- **Пакетный экспорт**: Одновременное сохранение набора изображений в нужных размерах для всех выбранных маркетплейсов одним кликом.
- **Полная приватность**: Вся обработка изображений происходит локально в браузере с использованием Canvas API. Данные не покидают ваше устройство.

## ⚙️ Как запустить локально
Проект не требует сборки, серверной части или установки зависимостей (Node.js и т.д.).
1. Скачайте файлы репозитория или откройте проект через GitHub Pages.
2. Откройте файл `index.html` в любом современном браузере.
3. Загрузите фото товара и начните работу. Все настройки сохраняются автоматически в LocalStorage.

## 🛠️ Технологии
- HTML5, CSS3 (Grid/Flexbox, CSS-переменные, адаптивная вёрстка)
- Нативный JavaScript (ES6+)
- Canvas API для сложной манипуляции пикселями, рендеринга слоёв и экспорта изображений
- LocalStorage для сохранения состояния приложения и пользовательских библиотек
- *Отсутствие зависимостей: максимальная скорость загрузки и чистая архитектура.*
